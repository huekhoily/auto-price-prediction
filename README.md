# Used Car Price Prediction Project

## Overview
This project analyzes used car data to understand the factors associated with vehicle prices and to build a machine learning model for price prediction.

## Project Goals
- Clean and preapre the used car dataset
- Perform exploratory data analysis
- Identify important relationships between vehicle factors and price
- Build and evaluate a price prediction model

## Tools
- Python
- SQL
- pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- scikit-learn
